AgriSense Website Plan

Site Name

AgriSense Storage Dashboard

This name reflects a smart agricultural monitoring system designed to track environmental conditions.

Site Purpose

The website allows users to monitor storage facility conditions such as temperature and manage safe thresholds.

Scenarios

  • What is the current storage temperature?
  • How can I adjust the safe temperature limit?

Color Scheme

Green (#2f855a) for headers and highlights.

Light gray (#f4f7f6) for background.

Typography

Roboto Slab for headings.

Open Sans for body text.
